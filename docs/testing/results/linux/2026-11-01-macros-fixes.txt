Resolved findings:
- Shared expansion/depth validation, one graph analysis and usage pass per refresh.
- Transactional rename validation after reference updates, including swaps;
  the editor draft follows the committed references and cannot restore old IDs.
- A trailing pause remains active and delays queued macro runs.
- Nested macros preserve their own timing overrides and inherit global defaults.
- Macro commands wait for successful completion without blocking keyboard input;
  launch/exit failures stop the sequence and clear queued runs.
- Stop, reconfiguration and timeout revoke command jobs; Linux cancellation kills
  the command process group. Disabled commands reject the whole macro before output.
- Queue overflow and timeout reach the shell as typed events and translated notices.
- Step-local errors, visible unapplied draft, confirmed discard, New macro remains
  available while correcting errors, and referenced macro deletion is guarded.
- Self-references do not block deletion: they disappear with their macro.
- Documentation, changelog and all 20 non-English PO catalogs updated.
