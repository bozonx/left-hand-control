Scope / remaining limits
- Preserve every offered format or reject before takeover: the existing
  64 MiB / 128 format / 2 second snapshot bounds are intentional. No lossy fallback.
- A GNOME RemoteDesktop session must remain while it serves restored MIME data;
  its indicator can remain until another copy. This cannot be hidden by closing
  the session without risking clipboard loss. Two sessions can overlap after a
  mode change; reusing EIS sessions across mechanisms would violate the API.
- Original clipboard ownership cannot be returned by these protocols. History
  duplicates and loss on Tecloid exit without clipboard-manager persistence remain.
  Sensitive-marked sources are rejected; unmarked secrets cannot be identified.
- Embedded terminal focus is not observable from window class. Shift+Insert can
  use PRIMARY there; choose main Ctrl+V. Legacy terminals need suitable CLIPBOARD
  bindings. Explicit user KeyC/V/X chords remain physical.
- Metadata-only focus detection cannot distinguish two windows of one app.
  Unknown Linux targets have no identity guarantee.
- Real compositor ACK fault injection, 4K Qt/LibreOffice offers, GNOME consent
  denial/reset/grant, receiver races, idle wakeup profiling and the full GNOME
  matrix remain manual acceptance work. The native GNOME check above is a smoke.
- Windows/macOS native changes were not cross-compiled or run on those systems.
  UIPI/secure desktop limitations are not bypassed. X11 support was not extended.
- One unrelated ignored core synthetic timing/order test was not run separately;
  all ten mapper_e2e integration tests were run.
