Windows fixes and acceptance — 2026-10-22–23 (America/Argentina/Buenos_Aires)
Source: e8a73bc + working-tree fixes. No release published.

Product changes
- Independent input guard, started through a short-lived launcher. The owner
  waits for the actual guard PID and launcher exit before injecting input.
  taskkill /T of the owner no longer destroys its recovery process.
- Unicode SendInput down/up pairs are paced by 30 ms per UTF-16 unit. This
  includes surrogate halves: lower delays reproduced corruption in real Notepad.
  Progress renews the text-job idle deadline; long progressing text is no longer
  cancelled merely for exceeding 15 seconds. Focus/generation cancellation stays.
- Scope limits: approximately 33 UTF-16 units/second; killing BOTH owner and
  independent guard cannot guarantee recovery. Other application/IME fixtures,
  physical hardware, long soak and hosted release artifacts remain separate gates.

Automation/stand fixes
- WTS session lock state; recheck before entering disposable-VM credentials.
- Three real S3/wakeup cycles, unchanged boot time and exact mapper output after
  EACH wake, without restarting mapper or replugging the keyboard.
- Owner-tree crash requires Ctrl held before kill and released after kill BEFORE
  physical/corrective input. Real Notepad uses UI Automation, exact small Unicode
  and >15-second text; failure artifacts preserve expected/actual/events/screen.
- Guest UTC verified/corrected before source upload. Identical future-dated source
  is recopied, avoiding Cargo cache poisoning from the supplied +7-hour RTC skew.
- --suite release checks release input/popups without claiming native tests;
  --mapper-only is explicitly a partial diagnostic with named SKIPs.
- Packager and e2e build the same app+stand target set, preventing dev-dependency
  feature-union recompilation. Only the application is included in the ZIP.
