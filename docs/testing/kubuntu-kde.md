# Kubuntu 26.04, Wayland

## Стенд и объём

Отдельная KDE Plasma 6 Wayland VM; пакет **tar.gz**. Общие требования,
полный перечень сценариев и локальные UI/mapper-тесты — [KDE Wayland](linux-kde.md).
Подготовка базового образа и `vm.json` — [руководство VM](../development/guide.md#l4-e2e-в-виртуальных-машинах).
VM, SSH-ключ, кэш и пакеты хранить вне Git. Install/remove/reinstall в `vm.json`
должны соответствовать выбранному формату пакета.

Зафиксированная VM построена на Ubuntu 26.04.1 с kubuntu-desktop. Установщик Kubuntu ISO этим не проверялся. Полный L4 выполнен для архива; отдельные проверки deb не заменяют полный L4 этого формата.

## Запуск

После [общих проверок](common.md) и сборки пакета:

```sh
python3 apps/slint-shell/scripts/vm/run-linux.py --vm /path/to/kubuntu2604 --package /path/to/left-hand-control-VERSION-linux-x86_64.tar.gz
```

Для теста перехода между версиями добавить `--previous /path/to/previous-package`.
Без предыдущего пакета не считать этот переход проверенным. `--show` показывает
экран VM, `--keep` сохраняет overlay. Логи находятся в каталоге запуска VM.

## Зафиксированный результат

[Полный прогон 2026-10-21](results/linux/2026-10-21-vm-kubuntu2604-2.txt):
**42 PASS, 0 FAIL** для указанного в отчёте tar.gz и SHA256.
Emoji hotkey больше не переключает VT; mapper автоматически восстанавливается
после QEMU USB-replug, включая Unicode. Unicode после второго экземпляра
также проверен. Пройдены lock/unlock, suspend/resume в VM,
переустановка поверх работающего процесса и удаление.

[Исторический прогон](results/linux/2026-10-19-vm-kubuntu2604-3.txt) имел
39 PASS и 2 FAIL в hotkey/replug; новый полный прогон закрывает эти два сбоя
для этой среды и пакета. Это не проверка всех режимов и физического железа.

## Что не принято

VM не принимает
физические устройства, Bluetooth, media keys, реальные sleep/wake и hotplug,
все экраны/DPI, сторонние приложения и полный [ручной чек-лист](manual-acceptance.md).
Конкретный отчёт определяет режим popup, portal, права, пропуски и пакет;
результаты другого дистрибутива не заменяют этот прогон.

Сводку оформлять по [политике результатов](results/README.md).
