# Скрипты репозитория

Скрипты конкретного приложения находятся в `apps/slint-shell/scripts/`.
Сборка релиза, e2e-стенды (включая VM) и проверка инсталлятора описаны в
[руководстве разработчика](../docs/development/guide.md).
Здесь остаются только общие инструменты и эксперименты вне приложения.

## Экспериментальные XKB-проверки

`experimental/xkb-test-install.sh` добавляет тестовую XKB-опцию `lhc:extras`.
`experimental/xkb-test-uninstall.sh` восстанавливает сохранённые правила.
Оба запускаются из корня репозитория. Они меняют системные XKB-файлы через
`sudo` и настройки клавиатуры KDE текущего пользователя; это ручной эксперимент,
а не часть автоматических тестов.
