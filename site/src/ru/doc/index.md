# Документация Left Hand Control

Left Hand Control — это настольный клавиатурный маппер: он перехватывает физическую клавиатуру, применяет слои, правила, макросы и команды, и отправляет результат через виртуальное устройство. Приложение также отображает быстрые всплывающие окна (эмодзи, быстрые действия) и сворачивается в системный трей.

## Начало работы

Этот раздел подготовлен для наполнения страницами документации:

- **Архитектура и концепции** — движок маппера, ввод-вывод устройств, события, наблюдатели
- **Установка и запуск** — Linux (KDE Plasma 6 Wayland, GNOME), Windows
- **Конфигурация и слои** — схема конфигурации, правила, аккорды, автопереключение
- **Действия и макросы** — клавиши, команды shell, системные действия, встроенные макросы
- **Всплывающие окна и интерфейс** — всплывающие окна layer-shell, системный трей
